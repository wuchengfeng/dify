# Starship 第二批页面低保真线框（草案 v0.1）

更新时间：2026-04-01

状态：第一阶段页面骨架补全中

适用对象：老板、前端负责人、CTO

文档目的：把第二批页面的结构先定下来，让版本、发布、进度这条线也完整。

## 1. 第二批包含哪 4 页

第二批页面是：

1. 主版本管理页
2. 学生进度页
3. 版本记录页
4. 我的发布页

这 4 页的作用不是“开课”，而是把课堂成果稳稳地接住。

## 2. 主版本管理页

这页的目标：

让教练清楚地维护唯一的正式版本。

### 2.1 页面骨架

```text
+--------------------------------------------------------------------------------+
| 顶部栏：主版本管理 | 当前小组 | 当前任务                                         |
+--------------------------------------------------------------------------------+
| 当前主版本                                                                      |
| 版本名：__________________   发布时间：______________                            |
| 版本说明：__________________________________________________                    |
+--------------------------------------------------------------------------------+
| 教练候选版本列表                                                                 |
| - 教练版本A   最近更新：10:20   [设为主版本]                                     |
| - 教练版本B   最近更新：11:10   [设为主版本]                                     |
| - 教练版本C   最近更新：11:45   [设为主版本]                                     |
+--------------------------------------------------------------------------------+
| 课堂共识说明                                                                     |
| - 为什么决定用这一版                                                              |
| - 这版吸收了哪些孩子的想法                                                        |
+--------------------------------------------------------------------------------+
|                                                      [保存说明] [发布主版本]     |
+--------------------------------------------------------------------------------+
```

### 2.2 页面必须说清楚的事

1. 当前哪一版已经是主版本。
2. 候选版本只能是教练自己的版本。
3. 这次发布为什么定这一版。
4. 发布后，学生会基于这一版继续做。

### 2.3 页面关键规则

1. 不能直接把学生版本设成 `main`。
2. 教练可以参考学生内容，但最后要落到自己的版本上。

## 3. 学生进度页

这页的目标：

让教练从“课堂现场”切到“全班总表”。

### 3.1 页面骨架

```text
+--------------------------------------------------------------------------------+
| 顶部栏：学生进度 | 当前任务切换 | 历史任务切换                                   |
+--------------------------------------------------------------------------------+
| 学生列表                                                                         |
| 名字   当前状态   最近测试   最近提交   最近更新时间   老师反馈   快捷操作        |
| A      进行中     10:25      -          10:26         已反馈     [查看]          |
| B      已测试     10:40      -          10:41         无         [查看]          |
| C      已提交     10:50      10:52      10:52         待处理     [查看]          |
| D      需修改     11:00      09:30      11:00         已退回     [查看]          |
+--------------------------------------------------------------------------------+
| 右侧详情区                                                                       |
| 当前学生：____________                                                           |
| 最近一次反馈：___________________________                                        |
| 当前版本摘要：___________________________                                        |
|                                            [去审核] [去看板]                     |
+--------------------------------------------------------------------------------+
```

### 3.2 这页要解决的核心问题

1. 全班谁在进行中。
2. 谁刚测过。
3. 谁刚提交。
4. 谁被退回后还没改好。
5. 老师下一步该盯谁。

### 3.3 这页和实时看板的区别

1. 实时看板看的是课堂现场。
2. 学生进度页看的是全班全局。

## 4. 版本记录页

这页的目标：

让孩子看懂自己一路怎么被推进的。

### 4.1 页面骨架

```text
+--------------------------------------------------------------+
| 顶部栏：版本记录 | 当前作品                                  |
+--------------------------------------------------------------+
| 时间线                                                        |
|                                                              |
| 11:20  已提交                                                |
|       说明：提交给老师查看                                   |
|                                                              |
| 11:05  已测试                                                |
|       说明：完成一次测试                                     |
|                                                              |
| 10:40  需修改                                                |
|       老师反馈：这里还可以更清楚                             |
|                                                              |
| 10:10  已提交                                                |
|       说明：第一次提交                                       |
|                                                              |
+--------------------------------------------------------------+
| 底部操作                                                     |
| [回到任务]  [查看当前作品]                                   |
+--------------------------------------------------------------+
```

### 4.2 这页设计原则

1. 不做复杂版本对比。
2. 先让孩子看懂发生了什么。
3. 老师反馈要看起来很清楚。

## 5. 我的发布页

这页的目标：

让学生把自己的公开版本发出去，而且知道规则。

### 5.1 页面骨架

```text
+--------------------------------------------------------------------------------+
| 顶部栏：我的发布 | 当前作品                                                     |
+--------------------------------------------------------------------------------+
| 左侧预览区                                                                      |
| - 封面预览                                                                      |
| - 手机端介绍页效果预览                                                          |
+--------------------------------------------------------------------------------+
| 右侧设置区                                                                      |
| 封面：_______________________   [上传]                                           |
| 一句话介绍：___________________                                                  |
| 作者名：_______________________                                                  |
|                                                                                |
| 当前可否发布：可以 / 不可以                                                      |
| 原因说明：_______________________                                                |
|                                                                                |
|                                                [保存] [生成公开链接并发布]       |
+--------------------------------------------------------------------------------+
| 发布结果区                                                                      |
| 公开链接：_______________________  [复制]                                       |
| 状态：已进入公共展示区                                                           |
+--------------------------------------------------------------------------------+
```

### 5.2 这页必须说清楚的事

1. 我现在能不能发布。
2. 如果不能，为什么不能。
3. 发布后会发生什么。
4. 作者名是我自己定义的公开名字。

### 5.3 页面默认保护

1. 引导孩子优先用昵称或作品名。
2. 不鼓励写真实联系方式。

## 6. 第二批页面的跳转关系

```text
实时课堂看板
  -> 学生进度页
  -> 版本审核页
  -> 主版本管理页

学生首页 / 任务工作区
  -> 版本记录页
  -> 我的发布页（仅主版本发布后可进入）
```

4. 教练审版本
