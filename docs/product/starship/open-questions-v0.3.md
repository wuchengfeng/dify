# Starship 第一阶段待确认问题（草案 v0.3）

更新时间：2026-04-01

状态：剩余少量问题待拍板

说明：这一版已经把上一轮拍板结果收进需求文档。这里只保留还会直接影响页面和流程的少量问题。

## 1. 一个学生能不能同时进行多个任务

问题：

同一个学生，在同一时间里，能不能同时做多个任务？

我的建议：

第一阶段允许。

原因：

1. 更符合真实教学。
2. 不会把后续课程安排做死。

## 2. 主版本到底怎么产生

问题：

教练最后要发布的主版本，有两种可能：

1. 只能是教练自己做出来的版本。
2. 教练也可以直接选某个学生版本，定为主版本。

我的建议：

第一阶段支持第 2 种。

原因：

1. 更贴近课堂真实情况。
2. 教练能直接认可优秀学生作品，不用多绕一步。
3. 页面流程也会更顺。

## 3. 实时课堂看板要不要支持“点学生切到中间主窗口”

问题：

看板上会同时显示教练和最多 6 个学生。教练要不要点一下某个学生，就把这个学生切到中间主窗口？

我的建议：

第一阶段建议支持。

原因：

1. 六个学生同时展示时，信息会比较密。
2. 教练在盯某个学生时，需要看得更清楚。

## 4. 本轮已经拍板的内容

这次已经确认的内容包括：

1. 学生个人版本公开后，自动进入公共展示区。
2. H5 介绍页第一阶段要有封面图。
3. 一个学生同一时间不能同时属于多个小组。
4. 实时看板第一阶段先不做“卡住提醒”。
