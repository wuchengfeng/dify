# Starship 第三批页面低保真线框（草案 v0.1）

更新时间：2026-04-01

状态：第一阶段页面骨架可闭环

适用对象：老板、前端负责人、CTO

文档目的：补齐传播和整理相关页面，让第一阶段从课堂到公开完全连起来。

## 1. 第三批包含哪 4 页

第三批页面是：

1. 我的作品页
2. 公共展示区
3. 作品介绍页
4. 作品体验页

这 4 页更偏整理和传播，不是课堂刚开始时最先要有的，但它们决定作品最后怎么被看见。

## 2. 我的作品页

这页的目标：

让学生分得清哪些作品还在做，哪些已经公开，哪些来自教练主版本。

### 2.1 页面骨架

```text
+--------------------------------------------------------------------------------+
| 顶部栏：我的作品 | 筛选                                                         |
+--------------------------------------------------------------------------------+
| 进行中的作品                                                                    |
| [作品卡A] [作品卡B] [作品卡C]                                                   |
+--------------------------------------------------------------------------------+
| 已发布的作品                                                                    |
| [作品卡D] [作品卡E]                                                             |
+--------------------------------------------------------------------------------+
| 来自主版本的作品                                                                |
| [作品卡F] [作品卡G]                                                             |
+--------------------------------------------------------------------------------+
```

### 2.2 每张作品卡至少要有

1. 作品名
2. 当前状态
3. 最近更新时间
4. 是否可发布
5. 是否来自主版本

### 2.3 这页最重要的作用

1. 帮孩子快速找到自己要继续改的作品。
2. 帮孩子区分“课堂里的作品”和“已经发出去的作品”。

## 3. 公共展示区

这页的目标：

让外部用户一进来就能浏览孩子们已经公开的作品。

### 3.1 页面骨架

```text
+--------------------------------------------------------------------------------+
| 顶部标题区：作品广场                                                            |
+--------------------------------------------------------------------------------+
| 筛选区：任务 / 小组 / 最近发布                                                  |
+--------------------------------------------------------------------------------+
| 作品卡片区                                                                      |
| [封面][作品名][作者名][一句话介绍]                                              |
| [封面][作品名][作者名][一句话介绍]                                              |
| [封面][作品名][作者名][一句话介绍]                                              |
+--------------------------------------------------------------------------------+
```

### 3.2 这页设计原则

1. 先做简单浏览。
2. 不做复杂活动感。
3. 手机端也能顺畅看。

## 4. 作品介绍页

这页的目标：

让外部用户先理解作品，再决定要不要体验。

### 4.1 页面骨架

```text
+--------------------------------------------------------------+
| 封面图                                                       |
+--------------------------------------------------------------+
| 作品名                                                       |
| 一句话介绍                                                   |
| 作者名                                                       |
| 来自哪个任务 / 小组                                          |
+--------------------------------------------------------------+
|                     [开始体验]                               |
+--------------------------------------------------------------+
```

### 4.2 这页必须做到的事

1. 一眼看懂这是什么作品。
2. 一眼看懂是谁做的。
3. 一眼知道下一步就是开始体验。

### 4.3 这页的重点

这页要优先按手机端 H5 来设计。  
也就是说，第一眼要干净、集中，不要像网页门户。

## 5. 作品体验页

这页的目标：

让外部用户真正体验作品。

### 5.1 页面骨架

```text
+--------------------------------------------------------------------------------+
| 顶部简栏：返回介绍页 | 作品名                                                   |
+--------------------------------------------------------------------------------+
|                                                                                |
|                            现有体验区域                                         |
|                                                                                |
+--------------------------------------------------------------------------------+
```

### 5.2 页面原则

1. 直接承接现有体验能力。
2. 不重新做一套新的体验系统。
3. 让外部用户从介绍页顺畅走到体验页。

## 6. 第三批页面的跳转关系

```text
我的作品页
  -> 我的发布页
  -> 版本记录页

公共展示区
  -> 作品介绍页
    -> 作品体验页
```
