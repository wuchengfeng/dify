# Starship 第一阶段待确认问题（草案 v0.5）

更新时间：2026-04-01

状态：核心问题已拍板，转入页面方案阶段

说明：这一版不再保留必须拍板的问题，改为记录默认保护建议，方便前端和后端后续对齐。

## 1. 关于作者名的默认保护建议

已经确认：

对外公开时，学生的作者名由学生自己定义。

我建议默认再加两层保护：

1. 系统提示优先用昵称或作品名。
2. 系统拦截明显的手机号、微信号等隐私信息。

## 2. 本轮已经拍板的内容

这次已经确认的内容包括：

1. 一个学生同一时间不能同时进行多个任务。
2. 主版本必须是教练自己的版本，不能直接把学生版本定为主版本。
3. 教练可以看到学生提示词，也可以手动吸收进自己的版本。
4. 教练发布主版本前，会先和孩子们达成共识。
5. 实时看板不需要支持“把某个学生切到中间主窗口”。
6. 实时看板要支持教练直接测试学生智能体。
7. 对外公开时，作者名由学生自己定义。
8. 学生已有进行中任务时，教练发新任务会自动结束旧任务，再发新任务。
